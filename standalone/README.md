# Поля — автономная читалка

Отдельная программа, без сервера, базы и интернета. Это один HTML-файл, конструктор: преподаватель открывает его в браузере, собирает из PDF или DOCX читалку со спрятанными заданиями и рассылает её студентам. Потом в том же конструкторе он открывает присланные отчёты.

## Как это работает

1. **Конструктор** (`polya-konstruktor.html`). Выберите книгу — PDF с текстовым слоем или документ Word (DOCX). DOCX делится на страницы примерно по 350 слов по границам абзацев и читается в режиме «Текст». Затем задайте норму чтения, вид по умолчанию и дедлайн, добавьте задания:
   - на странице: выбор варианта, выделение предложения или короткий ответ;
   - раскиданное по диапазону страниц: у каждого студента своя страница, короткий ответ.
   Задание назначается к открытой странице: её видно целиком, эталонное предложение выбирается щелчком.

   Задания можно загрузить пачкой («Загрузить задания из файла»): CSV из Excel, JSON или XML. Каждая строка проверяется так же, как в форме, ошибки видны до добавления; дальше «Добавить верные» или «Заменить все текущие». Шаблон CSV собирается на страницах вашей книги. Колонки: `тип` (выбор, выделение, короткий, раскидать), `стр_от`, `стр_до`, `задание`, `вар1`…`вар6`, `верный` (номер или текст варианта), `эталон` (текст предложения, можно начало). Формат XML — в «Образце XML». Текущие задания выгружаются в CSV и XML.
2. **Скачайте ключ преподавателя** (`polya-klyuch-….json`). В нём задания с верными ответами и ключ к отчётам. Храните его у себя: без ключа отчёты не открыть. После правки заданий скачайте ключ заново.
3. **Скачайте читалку для студентов** (`polya-chitalka-….html`) и разошлите её. Внутри книга и задания, но нет верных ответов и секретного ключа.
4. **Студент** открывает файл двойным щелчком, вводит ФИО и почту и читает. Страница считается дочитанной, когда пробыла в середине экрана половину расчётного времени чтения; при неактивной вкладке время стоит. На дочитанной странице появляется заметная янтарная плашка «Задание», которая пульсирует, пока её не открыли. Если студент открыл задание, не ответил и пролистал дальше, внизу появляется напоминание «Вернуться к заданию», а вверху — счётчик «Без ответа». Прогресс хранится в браузере. Кнопка «Сохранить отчёт» даёт файл `.polya`, его студент присылает преподавателю.
5. **Результаты.** Откройте конструктор, выберите ключ и загрузите отчёты, можно все сразу. Отчёты зашифрованы открытым ключом читалки, так что прочитать их можно только ключом преподавателя. Ещё они подписаны, поэтому изменённый файл не откроется. Выбор варианта и выделение проверяются автоматически, короткие ответы вы засчитываете вручную. Таблицу можно скачать в CSV для Excel. Несколько отчётов одного студента сливаются: берётся лучшее чтение и последние ответы. Ответы после дедлайна не засчитываются.

Чтобы поправить задания уже разосланной читалки, откройте ключ и тот же PDF, внесите правки, скачайте ключ и читалку заново и разошлите её снова. Студенты продолжат с того же места.

## Ограничения

- Нужен PDF с текстовым слоем (сканы не подходят) или DOCX. Старый формат Word (.doc) нужно пересохранить как .docx.
- Защита от подделки не абсолютная: ключ подписи лежит в файле читалки, и опытный человек может его достать. Ручную правку отчёта она отсекает.
- Дедлайн в читалке проверяется по часам компьютера студента.
- На iPhone файл, открытый прямо из письма, не работает: его нужно сохранить и открыть в браузере.

## Сборка

Нужен Node.js 22. Код читалки и шифрования общий с веб-приложением (`../web/src`), отдельно устанавливать веб-приложение не нужно.

```bash
cd standalone
npm install
npm run build        # dist/polya-konstruktor.html
npm test             # тесты
npm run typecheck
```

Собранный `dist/polya-konstruktor.html` — и есть программа: его можно копировать и открывать на любом компьютере.
