# Поля — автономная читалка

Отдельная программа, без сервера, базы и интернета. Это один HTML-файл, конструктор: преподаватель открывает его в браузере, собирает из PDF читалку со спрятанными заданиями и рассылает её студентам. Потом в том же конструкторе он открывает присланные отчёты.

## Как это работает

1. **Конструктор** (`polya-konstruktor.html`). Выберите PDF с текстовым слоем, задайте норму чтения, вид по умолчанию и дедлайн, добавьте задания:
   - на странице: выбор варианта, выделение предложения или короткий ответ;
   - раскиданное по диапазону страниц: у каждого студента своя страница, короткий ответ.
   Задания можно загрузить пачкой из XML: кнопка «Импорт из XML», формат — в «Образце XML». Пример:

   ```xml
   <tasks>
     <task type="choice" page="3">
       <prompt>Какую мысль автор считает главной?</prompt>
       <option>Первый вариант</option>
       <option correct="true">Верный вариант</option>
     </task>
     <task type="selection" page="5">
       <prompt>Найдите предложение, в котором автор вводит термин.</prompt>
       <answer>Начало эталонного предложения</answer>
     </task>
     <task type="short" page="7"><prompt>Сформулируйте тезис страницы.</prompt></task>
     <task type="scattered" from="10" to="20"><prompt>Перескажите страницу.</prompt></task>
   </tasks>
   ```

   Страницы нумеруются с 1. Для `selection` в `<answer>` достаточно начала фразы: регистр, кавычки и переносы не важны. Задания с ошибками не добавляются, причина видна под кнопкой. «Выгрузить задания в XML» сохраняет текущие задания в том же формате.
2. **Скачайте ключ преподавателя** (`polya-klyuch-….json`). В нём задания с верными ответами и ключ к отчётам. Храните его у себя: без ключа отчёты не открыть. После правки заданий скачайте ключ заново.
3. **Скачайте читалку для студентов** (`polya-chitalka-….html`) и разошлите её. Внутри книга и задания, но нет верных ответов и секретного ключа.
4. **Студент** открывает файл двойным щелчком, вводит ФИО и почту и читает. Страница считается дочитанной, когда пробыла в середине экрана половину расчётного времени чтения; при неактивной вкладке время стоит. На дочитанной странице появляется маркер задания. Прогресс хранится в браузере. Кнопка «Сохранить отчёт» даёт файл `.polya`, его студент присылает преподавателю.
5. **Результаты.** Откройте конструктор, выберите ключ и загрузите отчёты, можно все сразу. Отчёты зашифрованы открытым ключом читалки, так что прочитать их можно только ключом преподавателя. Ещё они подписаны, поэтому изменённый файл не откроется. Выбор варианта и выделение проверяются автоматически, короткие ответы вы засчитываете вручную. Таблицу можно скачать в CSV для Excel. Несколько отчётов одного студента сливаются: берётся лучшее чтение и последние ответы. Ответы после дедлайна не засчитываются.

Чтобы поправить задания уже разосланной читалки, откройте ключ и тот же PDF, внесите правки, скачайте ключ и читалку заново и разошлите её снова. Студенты продолжат с того же места.

## Ограничения

- Нужен PDF с текстовым слоем. Сканы не подходят.
- Защита от подделки не абсолютная: ключ подписи лежит в файле читалки, и опытный человек может его достать. Ручную правку отчёта она отсекает.
- Дедлайн в читалке проверяется по часам компьютера студента.
- На iPhone файл, открытый прямо из письма, не работает: его нужно сохранить и открыть в браузере.

## Сборка

Нужен Node.js 22. Код читалки и шифрования общий с веб-приложением (`../web/src`), отдельно устанавливать веб-приложение не нужно.

```bash
cd standalone
npm install
npm run build        # dist/polya-konstruktor.html
npm test             # тесты
npm run typecheck
```

Собранный `dist/polya-konstruktor.html` — и есть программа: его можно копировать и открывать на любом компьютере.
