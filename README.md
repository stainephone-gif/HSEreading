# Поля

Инструмент совместного чтения: спрятанные в тексте задания, пасхалки и экран результатов для преподавателя. Сейчас готов этап 0: каркас приложения, вход и курсы.

## Что уже работает

- Вход по одноразовой ссылке на почту, без пароля. Ссылка действует 15 минут и подтверждается кнопкой, чтобы почтовые сканеры её не сжигали.
- Создавать курсы могут адреса из `TEACHER_EMAILS`.
- У курса есть ссылка-приглашение для студентов. Её можно заменить, старая перестаёт работать.
- Преподаватель видит список участников курса.

## Структура

```
web/                 приложение на Next.js (App Router, TypeScript)
  prisma/            схема базы и миграции (PostgreSQL)
  src/lib/           доступ к данным: вход, сессии, курсы
  src/app/           страницы и server actions
  tests/             тесты Vitest (часть идёт на настоящей базе)
docker-compose.yml   база, миграции и приложение одной командой
```

На следующих этапах рядом с `web/` появится сервис разбора PDF на Python.

## Локальный запуск

Нужны Node.js 22 и PostgreSQL 16.

```bash
cd web
cp .env.example .env        # проверьте DATABASE_URL и TEACHER_EMAILS
npm install
npm run db:migrate          # создать таблицы
npm run dev                 # http://localhost:3000
```

Пока не задан `SMTP_URL`, ссылка для входа выводится в лог сервера.

Проверки перед коммитом:

```bash
npm run lint && npm run typecheck && npm test && npm run build
```

Тесты используют базу из `DATABASE_URL` и очищают её таблицы. Не запускайте их на рабочей базе.

## Запуск в Docker

```bash
docker compose up --build
```

Для сервера задайте в `.env` рядом с `docker-compose.yml` переменные `APP_URL`, `TEACHER_EMAILS`, `SMTP_URL`, `MAIL_FROM` и `POSTGRES_PASSWORD`.
